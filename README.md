Repositorio **público** con las imágenes y videos **ya aprobados** para Instagram y Facebook, para que Metricool los tome por enlace al programar. Los textos, fuentes y scripts viven en el repositorio privado `semana53/empresa` (`marketing/campanas/<campaña>/piezas/`).

Reglas (JuanCa, 9-nov):
- Aquí solo entra lo aprobado para publicar. Nada de borradores, bases ni datos.

- Carpeta por mes (`AAAA-MM/`); nombre `tema_formato.ext`.
